# Alien — fork notes

This repository is a personal fork of [openclaw/openclaw](https://github.com/openclaw/openclaw) renamed to **Alien** (logo 👾). Upstream's MIT license and copyright (Peter Steinberger, 2025) are preserved in [LICENSE](LICENSE).

## What was renamed

- `OPENCLAW_*` env vars → `ALIEN_*`
- `OpenClaw*` types and class names → `Alien*`
- `openclaw` lowercase identifiers (paths, packages, URLs) → `alien`
- `~/.openclaw/` config dir → `~/.alien/`
- CLI binary `openclaw` → `alien` (entry: `alien.mjs`)
- Workspace packages `@openclaw/*` → `@alien/*` (except external dep `@openclaw/fs-safe`, see below)
- Android Java packages `ai.openclaw.app` → `ai.alien.app`
- iOS / macOS source roots `OpenClawKit` → `AlienKit`, etc.
- CI workflow filenames `openclaw-*.yml` → `alien-*.yml`
- 🦞 → 👾

## What was preserved

- `LICENSE` — original upstream copyright
- `CHANGELOG.md` — historical record, untouched
- `pnpm-lock.yaml` — regenerated by pnpm
- `@openclaw/fs-safe` — this is an upstream-published external dependency at github.com/openclaw/fs-safe; not ours to rename
