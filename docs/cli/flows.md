# `alien tasks flow`

Flow commands are subcommands of `alien tasks`, not a standalone `flows` command.

```bash
alien tasks flow list [--json]
alien tasks flow show <lookup>
alien tasks flow cancel <lookup>
```

For full documentation see [Task Flow](/automation/taskflow) and the [tasks CLI reference](/cli/tasks).
